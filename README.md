# Graphic Comic Birthday Letter for Mio 💥🎂

A bold, graphic, comic/pop-art styled birthday website for Mio's 18th birthday. **Zero glassmorphism** — built with punchy comic speech bubbles, bold ink borders, Ben-Day halftone dot pattern, and hard drop shadows.

## 🎨 Features
- **Graphic & Comic Aesthetic**: Bold outlines, comic issue stickers (`ISSUE #18`), speech bubble dialogue cards, and pop-art halftone dots.
- **Alternating Dialogue Bubbles**: Each paragraph alternates between Left-aligned speech bubbles and Right-aligned speech bubbles like a graphic novel.
- **No Glassmorphism**: High-contrast, clean solid panels with retro offset block shadows.
- **Dark Mode / Light Mode**: Easily toggle between vibrant comic blue paper and deep midnight ink theme.
- **Smooth Dropdown**: Click the comic panel trigger to unfold the letter.
